# 오딘 길드 Flutter 앱

`odin_boss_schedule`의 모바일 프론트엔드다. 백엔드와 분리되어 있으며 REST API로만 통신한다.

## 현재 구현 범위

- 공통 디자인 시스템, 라우팅, 네트워크 오류, 보안 토큰 저장
- 로그인, 자동 로그인, 세션 복원, 로그아웃
- 가입 코드 회원가입·선택적 새 길드 생성(마스터), 내 정보 전체 편집(계정·캐릭터·부계정·장비·스킬)
- 보스 일정 조회, 서버 시각 카운트다운, 30초 동기화, 다중 유형 필터, 간략·상세 보기
- 기준 시각+남은 시간 일괄 계산, 한 건 등록, 날짜별 입력 초안, 고정 일정 자동 생성
- 스크린샷 OCR 확인 등록, 5분·1분·출현 앱 알림과 5분·1분·출현 음성 알림
- 컷·침공 종료·멍·삭제·전체 초기화, 일정 참여와 참여 보스 설정
- 일반·고정 보스 추가, 삭제, 나열 순서 저장, 기본 목록 복구
- 오늘·내일·지난 보스 투표, 참여 토글, 참여자 조회, 운영진 수동 투표 추가
- 길드룰·가격표 조회 및 운영진 등록·수정·삭제
- 길드룰 순서 변경과 보스 통제 상태 관리
- V2 아이템 컬렉션 개인 현황·길드 비교·분배 우선순위
- 콘텐츠 그룹 편성·미편성 길드원·운영진 배치 관리
- 공성전 시작 전·종료 후·사용 다이아 현황과 운영진 관리
- 손지원 요청 등록·신청·담당자 선택·상태 관리
- 컬렉션 정의·아이템 순서·우선순위 제외 관리
- 길드원 검색·능력치 정렬, 캐릭터·장비·스킬 비교 필터와 전체 상세 조회
- 길드장 역할 변경·위임·강퇴, 길드장/운영진 비밀번호 초기화
- 길드장 전용 길드 이름·전투력 수정 정책과 만료 없는 고정 가입 코드 생성·변경·관리
- 실제 일정·투표·공지 기반 홈 요약
- 기존 웹의 `Sand Gold`·`Dark Blue` 테마와 앱 아이콘 기반 `Icon Purple` 테마, 선택값 저장

짱깸보와 Discord 기능은 앱 범위에 포함하지 않는다.

## 화면 테마

- `Icon Purple`: 기본 테마. 앱 아이콘의 보라색 포인트와 부드러운 라벤더 surface를 사용한다.
- `Sand Gold`: 따뜻한 모래색 surface와 절제된 골드 포인트를 사용한다.
- `Dark Blue`: 깊은 남색 surface와 선명한 블루 포인트를 사용한다.

로그인 화면 우측 상단 또는 앱의 `전체 → 화면 테마`에서 즉시 변경할 수 있으며 선택값은 기기에 저장된다.

## 실행

기본 API 주소는 운영 HTTPS 서버인 `https://api.hanul-on.cloud`를 사용한다.
로컬 개발 서버를 사용할 때만 `--dart-define`으로 주소를 덮어쓴다.

```bash
# iOS 시뮬레이터 또는 로컬 기기 환경에 맞는 주소
flutter run --dart-define=API_BASE_URL=http://127.0.0.1:3001

# Android 에뮬레이터에서 호스트의 로컬 서버에 연결
flutter run --dart-define=API_BASE_URL=http://10.0.2.2:3001

# 별도 스테이징 API 주소 지정
flutter run --dart-define=API_BASE_URL=https://staging-api.example.com
```

실기기에서 로컬 서버에 연결할 때는 `127.0.0.1` 대신 컴퓨터의 LAN IP를 사용한다.
운영 빌드는 별도 설정 없이 HTTPS 운영 API를 사용한다.
